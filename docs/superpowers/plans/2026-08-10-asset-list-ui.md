# 资产持仓列表 UI 重设计实现计划

> **目标：** 在不改变资产编辑、分类、价格刷新、新增金额、删除和占比计算逻辑的前提下，将资产持仓区改为按分类分组的紧凑卡片列表。

## 方案

- 继续使用 `renderAssetSection()` 和现有 `data-asset-index` / `data-asset-field` / `data-action` 事件协议。
- 每个分类展示分类标题、资产数量、分类市值和分类占比。
- 每项资产展示名称、代码、价格/净值、市值、占比；代码、份额、固定金额等编辑字段放入原生 `details` 展开区。
- 保留资产区顶部的新增资产、刷新价格/净值、展开/收起按钮与金额提示。
- 添加响应式样式，桌面端单列卡片，窄屏端保持可读并避免页面横向滚动。

## 文件与验证

- 修改：`web/index.html` 的资产区渲染和对应 CSS。
- 修改：`web/tests/asset-table-layout.test.js`，验证卡片结构和原有事件字段仍存在。
- 验证：运行 `npm test`，确认所有前端和 NSDK 测试通过。
